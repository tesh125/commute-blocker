Commute Blocker — Privacy Policy

Last updated: 2026-09-17

What this extension does

Commute Blocker is a Chrome extension that reads your Google Calendar, looks for events with a location, and adds a "Commute" block before each one sized to the actual transit or driving time — plus an optional weather forecast and an "evening blocked" event after in-person events. It runs entirely from your own browser, using your own Google account.

Google Calendar data

The extension requests two Google Calendar scopes:

  • calendar.readonly — to read your events (start/end time, location, title) so it knows what to block time for.
  • calendar.events — to create the "Commute" and "Blocked until" events it generates, and to check whether it's already created one for a given event (so re-checking doesn't duplicate blocks).

This calendar data goes directly from your browser to Google's Calendar API — it never passes through, or is stored on, any server we operate. We (the extension's developer) never see your calendar contents.

Home location

Your home address (typed, or detected via your browser's geolocation) is used as the starting point for every commute-time calculation. It's stored in Chrome's synced storage, tied to your own Google/Chrome sign-in — not sent to or stored on any server we operate, except as part of the per-request routing calls described below.

Maps, Routes, and Weather data

To calculate a commute time and (optionally) a weather forecast, the extension sends the origin/destination address or coordinates and a target arrival time to a small server-side proxy we run, which forwards the request to Google's Routes, Geocoding, and Weather APIs using our own API key. This exists so you never need your own Google Maps API key.

These requests are processed and immediately discarded — we do not log, store, or retain the addresses, coordinates, or routes in a database. The proxy keeps only a short-lived, in-memory request count (to enforce a fair-use rate limit) keyed to a random identifier generated by your own install, which is not tied to your Google identity or any personal information.

What's stored, and where

  • Chrome synced storage (follows your Chrome sign-in across devices): home address, buffer/timing preferences, transit/driving preferences, and the calendar chosen for generated blocks.
  • Chrome local storage (this device only, never synced): a randomly generated per-install client ID, and an optional shared-proxy access code if you were given one.
  • Nowhere else. We do not operate a database of user data, accounts, or calendar contents.

What we don't do

  • We don't sell or share your data with third parties.
  • We don't use your data for advertising.
  • We don't use your data to train AI/ML models.
  • No human at Commute Blocker reads your calendar data — it never reaches us.

Google API Services User Data Policy

Commute Blocker's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access / deleting your data

You can revoke Commute Blocker's access to your Google account at any time from your Google Account's third-party access settings. Uninstalling the extension removes all locally/synced-stored settings from Chrome. Since we don't retain your data server-side, there is nothing further to delete on our end.
